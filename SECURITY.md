# Security Policy

VEAP handles sensitive health information. If you find a vulnerability, please do **not** open a public issue. Email the maintainers privately with reproduction steps; we aim to acknowledge within 72 hours.

See `docs/security.md` for the threat model, implemented controls, and known gaps.

**This is a hackathon prototype. It has not had an independent security audit or penetration test and must not be used to store real patient data as-is.**
