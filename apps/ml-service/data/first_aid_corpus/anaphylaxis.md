# Severe allergic reaction (anaphylaxis)
id: anaphylaxis
keywords: allergic, anaphylaxis, swelling throat, hives, epipen, sting

1. Call your local emergency number immediately.
2. Use an adrenaline (epinephrine) auto-injector if one is available, in the outer mid-thigh.
3. Lay the person flat with legs raised (sit up if breathing is difficult).
4. A second dose may be given after 5-15 minutes if there is no improvement, per device instructions.
5. Be ready to start CPR.
